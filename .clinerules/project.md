# Beauty Connect — Brand Brief

## What it is
Beauty Connect es una plataforma que ayuda a personas que buscan servicios de belleza a encontrar profesionales de forma sencilla y confiable. Los usuarios pueden explorar profesionales según el tipo de servicio, consultar información relevante y encontrar una opción que se adapte a sus necesidades.

## Palette
- Primary: #D94F7D
- Accent: #F3A6BD — usar en botones, detalles destacados y elementos de interacción.
- Background: #FFF8FA

## Fonts
- Headings: Poppins
- Body: Open Sans

## Tone
Femenino, cercano, confiable. Not this: no debe sentirse como un directorio genérico, frío o excesivamente corporativo.

## Screens
- Selección de categoría de servicio (home)

## Stack, pinned
Plain HTML, CSS and JavaScript reading a local JSON file,
styled with Bootstrap 5 loaded from a
CDN. No framework, no npm, no build step.
