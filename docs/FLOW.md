# Beauty Connect – Navigation Flow

| | Selección de categoría de servicio | Listado de profesionales |
|---|---|---|
| **Purpose** | Permitir que la persona elija el tipo de servicio de belleza que está buscando. | Mostrar las opciones de profesionales disponibles dentro de la categoría seleccionada. |
| **Information shown** | Nombre de Beauty Connect, mensaje principal y categorías Uñas, Cabello, Maquillaje y Pestañas. | Categoría seleccionada, nombre del profesional, zona, precio desde y distintivo de perfil verificado cuando corresponda. |
| **Actions** | Elegir una categoría de servicio. | Revisar los profesionales disponibles y volver a las categorías. |
| **Navigation** | Es la primera pantalla al ingresar. Elegir una categoría lleva al listado de profesionales. | Se llega al seleccionar una categoría. “Volver a categorías” regresa a la pantalla inicial. |
| **Empty / error state** | “No se pudieron mostrar las categorías en este momento. Intenta nuevamente.” | “Por el momento no hay profesionales disponibles en esta categoría.” |
