# Beauty Connect – Navigation Flow

| | Selección de categoría de servicio | Listado de profesionales | Perfil del profesional | Solicitar una cita |
|---|---|---|---|---|
| **Purpose** | Permitir que la persona elija el tipo de servicio de belleza que está buscando. | Mostrar los profesionales activos disponibles dentro de la categoría seleccionada. | Mostrar la información individual del profesional seleccionado y facilitar el contacto directo por WhatsApp. | Permitir que una persona envíe una solicitud de cita con sus datos de contacto, profesional, servicio, fecha y mensaje. |
| **Information shown** | Nombre de Beauty Connect, mensaje principal y categorías Uñas, Cabello, Maquillaje y Pestañas. | Categoría seleccionada y tarjetas con fotografía, nombre, zona, precio desde, distintivo de perfil verificado cuando corresponde y la opción visible **“Ver perfil →”**. | Fotografía, nombre, categoría, descripción, zona, precio desde, distintivo **“Perfil verificado”** cuando corresponde, enlace **“Volver a profesionales”** y botón **“Contactar por WhatsApp”** cuando el número es válido. Los datos provienen de `data/products.json`. | Formulario con los seis campos `nombre_cliente`, `telefono`, `profesional`, `servicio`, `fecha_solicitada` y `mensaje`, además del botón **“Enviar solicitud”** y el enlace **“Volver al inicio”**. |
| **Actions** | Elegir una categoría de servicio. También se puede acceder al formulario mediante **“Solicitar una cita”**. | Revisar los profesionales, seleccionar la tarjeta o la indicación **“Ver perfil →”**, regresar a las categorías o acceder a **“Solicitar una cita”**. | Consultar el perfil, regresar al listado de la categoría seleccionada o abrir el enlace de contacto por WhatsApp. | Completar los seis campos obligatorios, enviar la solicitud o regresar al inicio. |
| **Navigation** | Es la primera pantalla al ingresar. Elegir una categoría abre el listado filtrado. **“Solicitar una cita”** abre `solicitar-cita.html`. | Se llega al seleccionar una categoría. La tarjeta completa es un enlace a `perfil-profesional.html?id={id}&category={categoría}`. **“Volver a categorías”** regresa a la selección inicial. | Se llega desde la tarjeta del listado. **“Volver a profesionales”** regresa a `index.html` con el parámetro `category`, que abre nuevamente el listado correspondiente. **“Contactar por WhatsApp”** abre `https://wa.me/` en una pestaña nueva con un mensaje que menciona el nombre y la categoría. WhatsApp es un servicio externo; después de abrir el enlace, la persona continúa en WhatsApp Web o en su aplicación. | Se llega mediante **“Solicitar una cita”**. **“Volver al inicio”** regresa a `index.html`. Al enviar, se inserta una fila en la tabla `solicitudes_cita` de Supabase. |
| **Loading / processing state** | No aplica. | Mientras se carga `data/products.json`, se muestra **“Buscando profesionales”** y el mensaje **“Estamos preparando las opciones de {categoría}.”** | Mientras se carga `data/products.json`, se muestra **“Cargando perfil”** y el mensaje **“Estamos preparando la información del profesional.”** | Mientras se procesa la solicitud, el botón queda deshabilitado y muestra **“Enviando…”**. Al finalizar, vuelve a habilitarse con el texto **“Enviar solicitud”**. |
| **Empty / error state** | No aplica. | Si falla la carga, se muestra **“No pudimos cargar los profesionales”** y **“Intenta nuevamente en unos momentos.”** Si la categoría no tiene profesionales activos, se muestra **“Aún no encontramos opciones aquí”** y **“Por el momento no hay profesionales disponibles en esta categoría.”** Ambos estados permiten volver a categorías. | Si el `id` está ausente o no es válido, se muestra **“Perfil no disponible”**. Si el profesional no existe o está inactivo, se muestra **“Profesional no encontrado”**. Si falla la lectura de `data/products.json`, se muestra **“No pudimos cargar el perfil”**. Si el dato `whatsapp` está ausente o no contiene entre 8 y 15 dígitos, no se muestra el botón y aparece **“El número de WhatsApp de este profesional no es válido.”** | Si el envío se completa, el formulario se limpia y se muestra **“¡Gracias! Tu solicitud de cita fue enviada correctamente.”** Si falla, se conservan los datos y se muestra **“No pudimos enviar tu solicitud. {detalle del error}”** o **“Intenta nuevamente.”** cuando no hay detalle. |
